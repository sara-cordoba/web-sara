# Capturas de antes y después

Aquí van las dos capturas de cada comparación.

## Ahora mismo no hay ninguna, y es a propósito

Casi ningún proyecto tiene un "antes" que enseñar:

- **Ser Annora** y **Ajedrez Sistémico** eran webs nuevas, no rediseños. No
  existe una versión anterior.
- **Cronos AI Consulting** sí: hubo dos versiones anteriores en Odoo v17 antes
  de la web actual. Es el único caso real, y hace falta encontrar capturas de
  aquellas.

**Donde esto vale de verdad es en la campaña de clientes**, porque ahí el
"antes" es la web que ya tiene el cliente y el "después" la que se le entrega.
Por eso el componente se queda montado aunque hoy no se vea.

## Cómo añadir un caso cuando haya material

1. **Dos capturas del mismo tamaño**, encuadrando lo mismo. Si una está más
   cerca o más lejos que la otra, el deslizador enseñará trozos desalineados y
   el efecto se pierde. Lo suyo: **1600x1000 px, en `.webp`**.

2. **Añade el caso** en `src/data/antes-despues.ts` con el título, los dos
   nombres de archivo y, si quieres, una línea de qué cambió.

Con un caso se ve a lo ancho; con dos o tres, en dos columnas.

## Si la web vieja ya no existe

Sirve una captura del Internet Archive (web.archive.org). Si la usas, dilo en
la nota del caso: no es lo mismo una captura real que una recuperada.
